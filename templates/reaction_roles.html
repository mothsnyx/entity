How to Get IDs
📋 Role IDs:
  1. Enable Developer Mode in Discord (Settings → Advanced → Developer Mode)
  2. Right-click on any role in Server Settings → Roles
  3. Click "Copy ID" to get the role ID
  4. Paste the ID into the "Role ID" field above
📍 Channel/Thread/Forum IDs:
  • Regular Channel: Right-click the channel → Copy ID
  • Thread: Right-click the thread → Copy ID
  • Forum Post: Right-click the forum post → Copy ID

Tip: You can use Unicode emojis (🎮, 🎨, etc.) or custom Discord emojis (:emoji_name:)
